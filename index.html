WHO IS THE GHOST?

Welcome to the GHOST WEB investigation. Analyze the publicly available information and distinguish facts from assumptions.

Investigation started. Good luck!

01 — Investigation Scope

  • Analyze public website information.
  • Examine public DNS records.
  • Review HTTP response headers.
  • Identify publicly exposed information.

02 — Investigation Rules

  • Use authorized passive reconnaissance.
  • Do not attempt unauthorized account access.
  • Do not attack unrelated networks.
  • Document evidence for every finding.

03 — Your Mission

Can you identify the hosting provider? Can you distinguish the server IP from the website owner's personal IP? Can you prove the owner's identity using public evidence?

A claim without evidence is not a finding.

04 — Training Notice

This is a fictional educational challenge. It contains no real personal information, credentials, or private network data.
